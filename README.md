# longsword

可试玩的网页单机 RTS。只需 Node.js 22 或更高版本，不需要安装依赖。

## 启动

Windows 双击 `启动游戏.cmd`，保留打开的终端。也可在项目目录运行：

```sh
node server.mjs
```

然后打开 http://127.0.0.1:4173 。关闭服务终端即可停止服务。不要直接双击 `index.html`。

## 游玩

- 左键点选或拖动框选，Shift 追加选择。
- 双击己方单位，选择当前镜头内可见的我方同类单位。
- Ctrl + 数字 0–9 保存编队，数字键选中对应编队；重新开始后清空。
- 右键移动或攻击可见敌人。A 后左键指定位置，沿途自动交战。
- Shift + 右键依次追加移动路径点；普通右键、A 指令或 S 清空队列。
- 默认绕行山地；在山地上右键双击，允许本次路线穿越山地，山地减速仍生效。
- S 停止移动并停火；再下新指令恢复。进入敌方视野仍会被发现。
- 滚轮缩放，中键按住拖动；空格暂停／继续；小地图点击定位。
- 右侧训练盾兵、弓箭兵。向东侦察，摧毁两处营地获胜。
- 三档滑钮切换玩家、全局、BOT 视角，只影响观察。
- “打开独立观察窗口”共享同一场战斗，两个窗口各自调整视角。请使用同一浏览器，保持主窗口打开。
- 支持暂停、2 倍速、重新开始。刷新主窗口会开始新战局。

浏览器若拦截弹窗，可使用按钮下方的观察页链接。独立观察网址是在主窗口完整网址后追加 `&observe=1`；保留 `session` 参数。

## 验证

```sh
node tests/core.test.js
```
