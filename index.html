OPERATION REFERENCE

操作速查

选择

  • 左键点选己方单位或建筑；拖动框选单位
  • 左键双击单位：选中画面内同类
  • Shift+左键：追加选择，再点一次取消
  • Ctrl+0–9保存编队；0–9召回编队
  • F2：选中全部进攻性可移动单位

移动与战斗

  • 右键点击地面：移动，到达后警戒
  • Shift+右键：追加移动路径点
  • 右键双击：本次路线允许穿越山地和森林
  • 右键点击敌人：部队攻击，或让选中的攻击建筑指定目标；A后左键点击：攻击移动
  • H按住：显示选中单位或建筑的普通 / 防空射程
  • S：停火，新指令恢复交战
  • 右键点击未完工建筑：补派施工人员
  • 右键点击己方哨塔：入驻；选中哨塔按E：全部退出
  • 选中信鸽后右键双击：起飞或降落

建造与生产

  • B：建造菜单；C基地 R采矿场 Q哨塔 F食物厂 M机械工厂，最后左键选址
  • 采矿场只能建在矿点上，食物厂建在食物点上产量翻倍
  • 选中已完工基地：训练步兵；选中机械工厂：生产机械单位
  • Y后左键点击：设置该建筑的集结点
  • 未选中单位或选中基地时按R：科技面板
  • 选中己方建筑：右侧栏可拆除（不退款）

界面

  • 空格：暂停 / 继续；顶栏倍速按钮 1× → 2× → 4×
  • 滚轮缩放镜头，中键拖动平移；左键点击小地图定位
  • Esc：取消建造、攻击移动或集结点的待点击状态
  • 顶栏视角滑钮：玩家 / 全局 / BOT 视角

打开速查时战局自动暂停，关闭后恢复打开前的状态；关闭可点右上角 ×、按 Esc 或点击面板外区域。
