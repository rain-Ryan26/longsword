# 初版实现

性能与代码方案见 [技术设计：性能与窗口同步](../技术设计/性能与窗口同步.md)，与游戏设计分开维护。

## 文件职责

- `src/data.js`：兵种数值、固定地图和巡逻路点。
- `src/ai.js`：各关卡 BOT。均衡对抗通过核心指令训练、建造、侦察和集结反击。
- `src/pathfinding.js`：八方向 A*、阻挡检查、附近可走目标。
- `src/core.js`：固定步长战斗、BOT、迷雾、训练、胜负和快照。不依赖浏览器。
- `src/renderer.js`：Canvas 地图、圆形单位、箭矢、小地图和镜头。
- `src/app.js`：鼠标键盘、面板、观察窗口快照同步。
- `server.mjs`：仅监听本机的静态服务器，无第三方依赖。

## 验证记录（2026-09-10）

- 10 项 Node 测试通过：绕障与不可达路径、阵营迷雾、探索记忆、S 停火和恢复、箭矢伤害与暴露、训练和人口、巡逻、建筑解除阻挡、胜负、双营地完整进攻。
- 完整进攻测试通过持续训练增援和定期攻击命令获得胜利，尚未证明所有阵型或数值都平衡。
- 浏览器实际验证：页面绘制、框选 14 人、S 全体停火、新指令恢复、训练出兵、视角切换、滚轮缩放。
- 两个浏览器页面已验证同一战局的时间、资源和暂停状态同步；观察页控制按钮禁用。
- 内置浏览器未将按钮弹出的窗口列入可操作页面，因此同步验证使用相同 session 的独立观察页。普通浏览器弹窗体验仍需用户机器实测。
- 中键平移已实现；本轮自动化工具没有带中键的拖动接口，未做自动交互验证。
- 操作调整已在独立浏览器页验证：空格暂停后时间和资源保持不变，再按继续；右侧指令按钮移除后，A 仍可进入攻击移动，S 仍可使选中部队停火。
- 编队与双击已在独立浏览器页验证：14 人编队保存和召回、覆盖编队、重新开始清空；8 名盾兵中一半移出镜头后，双击只选中画面内 4 人，全局观察下也不选镜头外单位，数字键仍可召回完整编队。
