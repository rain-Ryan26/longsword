# 代码索引

> 用途：在提问或改动前快速定位某块逻辑对应的源码、测试与设计文档。
> 改代码前先查对应测试（见“测试”），改设计先看设计文档（见“文档映射”）。

## 总体结构

```
index.html              单页入口，所有 DOM 结构与按钮定义（无 JS 逻辑）
style.css               全部样式
src/                    游戏逻辑（ES Module）
tests/                  测试（node --test）
assets/audio/           音效资源
docs/                   design 设计 · 实现 笔记 · stage 阶段 · 技术设计
```

## 启动与装配

- `index.html`（入口脚本 `<script type="module" src="src/app.js">`）
- `src/app.js` — **应用装配 / 主循环**：创建 `Game`、`Renderer`、`Hud`、合成右键菜单、绑定所有 DOM 事件、BroadcastChannel 多窗口同步、定时推进 `game.step` + 渲染 `frame`。全局状态（selected/paused/speed/view 等）都在这。
  - 观察者模式由 URL 参数 `?observe=1` 启用。
- `server.mjs` / `启动游戏.cmd` — 本地静态服务器。

## 核心模拟

- `src/core.js` — **`Game` 类，模拟核心**：`step(dt)` 总调度（科技、建造、训练、AI、迷雾、密度、单位、哨塔、分离、弹道、清理、胜负）。所有玩法命令入口：`command` / `build` / `demolish` / `train` / `research` / `enterTower` / `exitTower` / `setRallyPoint` / `assistBuild`。胜负判定 `updateResult`。战场查询 `snapshot` / `canSee` / `acquireTarget` / `attackRange` / `attackDamage` 等。
  - 子逻辑委托给下面各模块（import 关系即分层入口）。

## 功能模块（src/ 按职责）

| 模块 | 职责（焦点） | 主要导出 |
|------|-------------|---------|
| `data.js` | 静态数值与常量 | `STATS`（单位/建筑数值）、`TECHNOLOGIES`（科技）、`popOf`、`usedPop`、`createMap*`（各关卡基础地图） |
| `rules.js` | 游戏规则规则 | `TRAINABLE_TYPES`、`BUILDING_TYPES`、`productionType`、`populationCap`、`researchError`、`trainingPlan`、`foodRate`、`isArmyUnit` |
| `pathfinding.js` | 寻路与通行 | `findPath`(A*) 、`walkable`、`buildingCells`、`nearestFree`、`spawnPoint`、`createWalkability` |
| `units.js` | 单位移动/攻击/索敌 | `stepUnits`、`move`、`performAttack`、`invalidateMovement` |
| `queries.js` | 空间索引（性能） | `NearbyIndex`、`indexEntities`、`nearbyEntities`、`earlierEntity` |
| `separation.js` | 单位拥挤分离 | `separateUnits` |
| `vision.js` | 战争迷雾/视野 | `VisionSystem` |
| `flight.js` | 飞行单位（信鸽） | `stepFlight` |
| `garrison.js` | 哨塔驻军 | `enterTower`、`exitTower`、`occupants`、`destroyGarrison` |
| `ai.js` | 敌方 AI | `DefendAI`(进攻关)、`AssaultAI`(防守/沙盒)、`BalancedAI`(均衡，可接管玩家 0) |
| `defense.js` | 防守关波次 | `startNextDefenseWave`、`defensePresentation` |
| `levels.js` | 关卡配置与布阵 | `LEVELS`、`ATTACK_SETUP`、`createLevelMap`、`setupLevel` |
| `random-map.js` | 随机进攻关地图生成 | `createMapRandomAttack` |
| `sandbox.js` | 沙盒布阵 | `placeSandboxUnit`、`deleteSandboxUnits`、`startSandboxBattle`、`mirrorSandboxFormation`、`restoreSandboxSetup` |
| `tutorial.js` | 教程分步引导 | `Tutorial`、`TUTORIAL_STEPS` |

## 渲染与界面

- `index.html` — 全部 DOM：顶栏资源/视角、关卡选择、战术地图、右侧单位/建造/科技/训练面板、操作速查、设置、教程面板。**DOM id 即按钮标识**。
- `renderer.js` — `Renderer`：画布渲染、相机、小地图。
- `hud.js` — `createHud`：更新右侧选中面板/资源/建造菜单等文本状态。
- `audio.js` — `AudioManager`：音效播放与音量设置。

## 输入与交互

- `input.js` — `bindInput`：鼠标/键盘/滚轮，选择、移动、攻击、建造放置、框选、编队（`F2`、Ctrl+数字）、方向。
- `interaction.js` — `InteractionState`：交互模式状态机（select/place/attack/rally 等互斥）、建造成本与预览 `buildPreview`。
- `selection.js` — `ControlGroups`（编队）、`nearestEntity`、`isOffensiveMovableUnit`。

## 同步与多窗口

- `sync.js` — `SnapshotHost` / `SnapshotReceiver`：主窗口向观察窗口广播快照。

|------|------|
