# 网页单机初版

本文件是 2026-09-10 用户授权实施的范围。原《设计要点》保留为远期想法；冲突处以本文件为准。

- 只做地面盾兵、弓箭兵，用圆形和小图标表示。
- 单机对抗 BOT。两处资源营地各有建筑和驻军，另有固定路线巡逻队。
- 左键点选或框选；Shift 追加选择；右键移动；A 后左键攻击移动；S 停止移动并停火。新的移动或攻击指令恢复交战。
- 战争迷雾分未探索、已探索、当前可见。玩家／全局／BOT 三档滑钮只改变显示，不改变作战信息。
- 可打开独立观察窗口，与主窗口共享战局，每个窗口有独立视角和镜头。观察窗口不发指令。
- 滚轮以鼠标为中心缩放，中键拖动镜头；空格暂停／继续。完整操作见 [操作列表](操作列表.md)，界面布局见 [GUI 设计](GUI设计.md)。
- 地图用 96 × 64 小格计算，只画每 8 格的大网格。山地和森林可通行，移速分别乘 0.2、0.6；侦测距离分别为基础值的 120%、30%。
- 弓箭有飞行和命中动画；显示血量、选择圈、命令提示和小地图。
- 玩家有基地、初始部队、食物和矿产，可训练两种兵。摧毁两座敌营获胜，基地被毁失败。
- 暂不做空军、高级兵、科技树、建造编辑器、联机、存档、复杂高度遮挡。

实现采用原生 JavaScript、Canvas 2D 和 Node 静态服务器，无第三方依赖。规则、数据、画面分开，后续可替换画面层。

## 完成顺序

1. 写清地图、单位数值、寻路、战斗、迷雾与多窗口规则。
2. 实现地图和独立规则核心，再接入 Canvas、操作面板与观察窗口。
3. 用自动检查验证核心规则，用浏览器检查操作和实际显示，补充启动说明与已知限制。
