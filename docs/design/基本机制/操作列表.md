# 操作列表

本文件集中记录当前操作，快捷键变更以这里为准。

| 操作 | 效果 |
| --- | --- |
| 左键点选 | 选择一个己方单位或建筑；建筑可在侧栏面板拆除；点击空地取消选择 |
| 左键按住拖动 | 框选己方单位 |
| 左键双击己方单位 | 替换当前选择，选中当前镜头画面内、当前可见的所有我方同类单位 |
| Ctrl + 数字 0–9 | 将当前选中部队保存到该编队，覆盖原编队 |
| 数字 0–9 | 选中对应编队的存活单位，不移动镜头 |
| F2 | 选中全地图内全部存活的己方进攻性、可移动单位；信鸽不计入 |
| Shift + 左键 | 追加选择；点选已选单位可取消该单位 |
| Shift + 框选 | 追加框内单位 |
| 右键点击地面 | 选中部队移动到此处，到达后警戒；落地信鸽自动起飞并绕目标盘旋 |
| 右键双击（选中信鸽） | 落地信鸽首次右键即起飞，紧接的第二击不会使其降落；已在飞行的信鸽前往点击位置降落。混选时其他单位维持原有右键规则 |
| 在山地或森林上右键双击 | 本次移动路线允许穿越山地和森林；仍按脚下地形移速移动 |
| Shift + 右键 | 追加移动路径点，按点击顺序依次到达；没有移动目标时从第一个点开始 |
| 右键点击己方未完工建筑 | 从选中部队补派施工人员，基地最多 6 人，采矿场最多 4 人，哨塔最多 2 人；实际派遣的施工人员自动取消选中 |
| 右键点击可见敌人 | 选中部队攻击该目标 |
| A，再左键点击 | 攻击移动，沿途攻击附近可见敌人 |
| B | 选中部队后打开侧栏建造菜单 |
| B → C | 选择建造基地，再左键选址 |
| B → R | 选择建造采矿场，再左键选址 |
| B → Q | 选择建造哨塔，再左键选址 |
| B → F | 选择建造食物厂，再左键选址 |
| B → M | 选择建造机械工厂，再左键选址 |
| R | 未选中单位，或选中己方基地时，打开／关闭科技面板 |
| Y，再左键点击 | 选中己方已完工基地或机械工厂后设置该建筑的集结点；此后生产完成的单位会自动避让山地和森林前往集结点 |
| S | 停火，部队继续当前移动；飞行信鸽保持盘旋。新移动或攻击指令恢复交战 |
| Esc | 取消建造、攻击移动、集结点的待点击状态或当前框选拖动 |
| 空格 | 暂停游戏，再按一次继续；不移动镜头，长按只触发一次 |
| 滚轮 | 以鼠标位置为中心缩放 |
| 中键按住拖动 | 平移镜头 |
| 左键点击小地图 | 将镜头移到对应位置 |

界面操作：顶部暂停／继续、倍速、重新开始，以及三档滑钮切换玩家／全局／BOT 视角；选中已完工基地可训练步兵，选中已完工机械工厂可生产机械单位并查看各自队列。

双击以单位中心是否落在战场画面内为准，镜头外或迷雾隐藏的单位不加入选择，即使开启全局视角也只选画面内单位。编队可以召回镜头外的成员；死亡成员自动忽略。空选择不覆盖编队，空编队不改变选择。重新开始或刷新后清空编队。

Shift + 右键只设置移动点，点击敌人也作为位置处理；已有目标位置保留，部队切换为移动模式。普通右键或 A 攻击指令会清空待经路径点。每个单位独立顺序行进，无需等全队到齐。

暂停和作战指令仅在主窗口有效。观察窗口只允许调整镜头和视角。暂停时仍可调整镜头、选择部队和下达指令，战斗与训练计时在继续后推进。滑钮获得焦点时保留其键盘操作，不触发游戏快捷键。
