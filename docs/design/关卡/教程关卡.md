# 教程关卡

原「玩法演示」关卡改为教程关卡，作为关卡选择左栏的入口之一，不新增关卡类型。

## 定位

- 新手入门关：用短主线教会「选择—移动—建造—生产—战斗」的核心循环，最后以摧毁东侧两座敌营结束。
- 地图、兵力、胜负规则沿用原演示关卡：96×64 地图，我方半场基地（12, 32）与机械工厂（6, 32），资源区块（24, 40），东侧两处敌营（各 30 名守军）与 10 名巡逻单位；我方 30 名地面部队、2 装甲车、2 蒸汽步行机；初始食物与矿产 5000，固定 200 人口。
- 与演示关卡的唯一规则差异：科技开局全部未研发，供教程教学研发操作。

## 引导面板

- 位于战场左上角，任务标题下方；标题淡出后上移。样式沿用现有深绿面板、灰绿描边与米黄强调色。
- 显示「教程 · 阶段 · 当前步 / 总步数」与当前步骤说明，提供两个按钮：
  - 跳过这一步：直接进入下一步。
  - 操作速查：打开完整操作表弹窗。
- 引导不阻塞操作，玩家可自由行动；操作型步骤只记录当前提示出现后的动作，避免玩家因提前操作而连续跳过未读提示。
- 主线不逐项考核所有快捷操作；双击同类、追加选择、路径点、小地图、驻塔、停火和观察视角等低频或进阶操作保留在「操作速查」。全部步骤完成后面板停留在「教程已完成」，并禁用跳过按钮。

## 操作速查

- 弹窗复用设置面板的视觉样式，按「选择／移动与战斗／建造与生产／界面」分组列出全部操作。
- 打开时自动暂停战局，关闭后恢复打开前的暂停状态。

## 步骤

| 阶段 | 步骤 | 完成条件 |
| --- | --- | --- |
| 基础操作 | 选择部队 | 点选或框选己方单位 |
| 基础操作 | 右键移动 | 右键点击地面 |
| 基础操作 | 镜头缩放与平移 | 使用滚轮缩放并使用中键平移 |
| 基础操作 | 创建并召回编队 | 保存编队后召回同一编队 |
| 建造与经济 | 打开建造菜单 | 按 B |
| 建造与经济 | 放置采矿场 | 在矿点上放置采矿场（吸附矿点） |
| 建造与经济 | 建造并补派 | 只派一名部队放置哨塔，再补派施工人员 |
| 建造与经济 | 训练部队 | 在基地训练一名部队 |
| 建造与经济 | 科技研发 | 打开科技面板并开始研发 |
| 建造与经济 | 设置集结点 | 按 Y 后点击地面设置集结点 |
| 战斗 | 攻击移动 | 按 A 后左键点击地面 |
| 界面 | 暂停与倍速 | 暂停战局并切换一次倍速 |
| 目标 | 综合演练 | 摧毁两座敌营 |
