# 沙盒模式

- 地图中央上下各一座山体，中间留通道，无森林，无初始部队、建筑、资源和战争迷雾。左半边为蓝方，右半边为红方。
- 右栏列出所有现有单位的图标与名字，点击兵种后点击地图放置；放置不扣资源、不限制人口。选择工具可点选、框选双方单位，编辑时 D 删除。
- 选定兵种并按住 Shift 移动鼠标，每隔 2 格放置一个单位；跨越中线后按所在半边归属阵营。松开 Shift 结束本段放置。
- 战场上方显示左右两边人口，机械沿用现有人口权重。
- 一键对称阵型用蓝方布阵覆盖红方，按地图竖直中线镜像兵种与位置。地面单位不能放置在山体上。
- 开始战斗保存布阵并启动模拟，玩家指挥蓝方，红方复用防守关卡总攻 AI，不补员、不生成波次；任一方全灭结束。
- 回到编辑恢复开战前的布阵、满生命和初始状态，可修改后再次开战。
